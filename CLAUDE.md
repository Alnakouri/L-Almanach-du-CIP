# L'Almanach du CIP — dépôt de démonstration

## Identité
- **Type** : Application Electron (Desktop) + PWA (Web)
- **But** : Plateforme d'apprentissage hors ligne, montrée ici avec un contenu entièrement fictif.
- **Version** : 1.49.2 (Mastery Edition v9.32.2) | Electron 44.0 | Cache SW v19-61

## Règles
- Tout le contenu de ce dépôt est inventé : Maison Horizon, Valbourg et leurs personnages n'existent pas.
- Seul le cadre public du titre professionnel (blocs CCP, compétences RNCP) est réel.
- Ne jamais ajouter ici un support de formation, même partiel, ni un texte qui en dérive.

## Commandes
- **Dev** : `pnpm start`
- **Vérifications** : `pnpm run check:all`, ce que rejoue la CI
- **Index** : `pnpm run build-rag` et `pnpm run build-vault` après toute modification du contenu
